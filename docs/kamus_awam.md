# Kamus Bahasa Awam Krisis Bensin Bali
Daftar kata yang sering dipakai dalam urusan bensin dan padanan kata sehari-harinya agar mudah dimengerti warga biasa.

---

| Kata Sulit / Istilah Resmi | Kata Sehari-hari (Pakai Ini) | Contoh Pemakaian |
|---|---|---|
| **nosel / nozzle** | selang pompa | "Bensin keluar dari selang pompa SPBU." |
| **stok fisik** | bensin yang benar-benar ada | "Bensin yang benar-benar ada di SPBU masih sedikit." |
| **stok** | persediaan bensin | "Persediaan bensin mulai terisi kembali." |
| **terminal / depo** | gudang besar bensin | "Gudang besar bensin di Sanggaran dan Manggis." |
| **tanker** | kapal pengangkut bensin | "Kapal pengangkut bensin sudah sandar di dermaga." |
| **mobil tangki** | truk bensin | "Truk bensin sedang keliling mengantar ke SPBU." |
| **waktu putar / siklus** | waktu keliling mengantar | "Truk butuh waktu keliling sekitar satu sampai dua hari." |
| **merata / terdistribusi** | sampai ke semua SPBU | "Bensin belum sampai ke semua SPBU." |
| **pelosok** | daerah yang jauh | "SPBU di daerah yang jauh paling lambat dapat kiriman." |
| **pasokan / suplai** | kiriman bensin | "Kiriman bensin dari kapal sudah masuk ke gudang." |
| **distribusi** | pengiriman ke SPBU | "Pengiriman bensin ke SPBU masih terkendala macet." |
| **kelangkaan** | bensin sulit dicari / bensin habis | "Bensin sempat sulit dicari di daerah Kuta dan Ubud." |
| **penguraian antrean** | antrean berkurang | "Antrean kendaraan baru berkurang mulai besok." |
| **pemulihan** | kembali normal | "Keadaan bensin diperkirakan kembali normal Minggu pagi." |
| **mereda** | berkurang / kembali tenang | "Kepanikan warga mulai kembali tenang." |
| **krisis** | keadaan sulit bensin | "Keadaan sulit bensin ini dipicu kapal yang terlambat." |
| **panic buying** | beli berlebihan karena takut kehabisan | "Warga beli bensin berlebihan karena takut kehabisan." |
| **simulasi** | hitungan perkiraan | "Hitungan perkiraan komputer menunjukkan stok cukup." |
| **Monte Carlo** | hitungan coba-coba ribuan kali | "Hasil hitungan coba-coba ribuan kali dengan angka acak." |
| **median** | titik tengah perkiraan | "Titik tengah perkiraan jatuh pada hari Minggu pagi." |
| **interval kepercayaan 80%** | perkiraan yang kemungkinan besar benar (8 dari 10) | "Kemungkinan besar benar antara Sabtu malam dan Senin siang." |
| **probabilitas** | peluang | "Peluang ada bensin sekitar 7 dari 10." |
| **skenario** | kemungkinan keadaan | "Ada beberapa kemungkinan keadaan di lapangan." |
| **indeks** | skor | "Skor kesulitan bensin di Denpasar cukup tinggi." |
| **baseline** | keadaan normal | "Orang beli bensin hampir dua kali lipat dari keadaan normal." |
| **korelasi** | keterkaitan | "Ada keterkaitan kuat antara panjang antrean dan bensin habis." |
| **lag** | jeda waktu | "Ada jeda waktu sekitar dua jam sebelum bensin habis." |
| **anomali** | kejadian tidak biasa | "Terjadi lonjakan antrean yang tidak biasa di malam hari." |
| **kalibrasi** | dicocokkan dengan kenyataan | "Hitungan komputer ini sudah dicocokkan dengan laporan warga." |
| **throughput** | jumlah kendaraan yang dilayani per jam | "Jumlah kendaraan yang dilayani sekitar 40 motor per jam." |
| **backlog** | antrean yang menumpuk | "Antrean yang menumpuk mulai terurai malam nanti." |
| **volatilitas** | naik-turun yang tajam | "Laporan warga naik-turun tajam antara siang dan malam." |
| **akurasi** | ketepatan | "Ketepatan tebakan model mencapai sekitar 7 dari 10." |
| **tren** | arah perubahan | "Arah perubahan saat ini menuju perbaikan." |
| **kapasitas** | daya tampung | "Daya tampung tangki SPBU mencapai 30 ribu liter." |
| **optimal** | paling baik | "Waktu paling baik cari bensin adalah tengah malam." |
| **signifikan** | cukup besar / nyata | "Terjadi penurunan antrean yang cukup nyata." |
| **eksponensial** | naik makin cepat | "Laporan bensin habis bertambah makin cepat saat sore." |
| **data** | angka / catatan | "Catatan laporan dari warga pengemudi ojek dan motor." |
| **KL (Kiloliter)** | ribu / juta liter | "Tulis 26 juta liter, jangan tulis 26.200 KL." |
